# CAR WAX Website

موقع تعريفي متجاوب لمغسلة CAR WAX:
- ألوان متناسقة مع الهوية: أسود وأبيض وأحمر.
- اللوجو الخاص بالمغسلة داخل `assets/logo.jpeg`.
- صورة قائمة الأسعار المرسلة داخل `assets/wash-prices.jpeg`.
- قسم أسعار يشمل باقات الغسيل، الكيماوي، خدمات الجنوط، والعروض والاشتراكات.
- عربي وإنجليزي مع زر تبديل اللغة.
- روابط الحجز والاستفسار على واتساب: `201099180302`.

## التشغيل
1. فك ضغط `car_wax_website.zip`.
2. افتح مجلد `car_wax_website` في VS Code.
3. افتح `index.html` في المتصفح، أو استخدم إضافة Live Server.
